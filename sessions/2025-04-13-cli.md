# Clawed Project Context - 2025-04-13

## Project Understanding
- Clawed is a tool to provide contexts to Claude
- It serves as an MCP server for Claude to retrieve project information
- Maintains separate directories per project, outside the projects themselves
- Projects can link to these directories as needed (e.g., for Serena)

## Architecture
- Clawed maintains its own repo with subdirectories for each tracked project
- Each project directory contains contexts organized by purpose (meetings, plans, issues)
- Supports different context types: Test, Markdown, Code
- Uses FastMCP for Claude integration
- Dynamic git metadata retrieval rather than static storage

## Implementation Details
- Context files stored in `sessions/<date>-<app>.md` format
- Chat histories stored in `sessions/`
- Each context includes timestamps and originating app info
- New sessions load recent contexts for continuity
- Real-time git integration for up-to-date project information
