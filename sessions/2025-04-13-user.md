# Clawed Project Context - 2025-04-13

## Project Understanding

Clawed maintains docs for other projects
These docs are used to provide information and context to Claude when it is working with those projects 
It does this primarily as an MCP server which provides memory, rules and access to projects' files

## Architecture

Docs are stored in sub-directories, one per project
More info about projects is gathered dynamically, at runtime, such as git metadata, tasks, ...
Sub-directories may contain links to local clones of a project's repository
Sub-directories will contain a variety of documents about their projects, e.g. contexts, meeting notes, desisgn decisions, ...
Most documents will be in Markdown format, although some other forats may be used

## Implementation Details

MCP server is based on FastMCP
Context files are stored in `sessions/` sub-directory, and prompts/procedures are stored in `howto/'
Write session files at end of each session, and read recent session files at start of a new session
